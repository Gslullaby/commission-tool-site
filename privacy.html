隐私政策

运营方：小斧科技团队 · 生效日期：2026年8月26日

1. 政策范围

本政策说明电商佣金计算工具如何处理直播佣金和剪辑佣金计算中涉及的数据。本介绍网站不提供账号注册，不使用广告追踪，也不接收用户的Excel或佣金文件。

This Policy explains how the E-commerce Commission Tool handles data used for LIVE and editor commission calculations. This informational website does not provide user registration, use advertising trackers, or receive users' Excel or commission files.

2. 处理的数据

本地业务文件

用户主动选择的主播排班表、订单明细表、视频登记表，以及工具生成的清洗表、匹配表、GMV汇总、异常复核表和佣金结果。

TikTok授权与视频数据

经TikTok账号持有人明确授权后，本工具通过官方接口获取授权账号的基本信息和视频列表，包括公开显示名称、账号标识、视频标识、发布时间和累计播放量。工具申请的权限为 user.info.basic 和 video.list。

With the TikTok account holder's authorization, the Tool retrieves basic account information and video-list data through official TikTok APIs, including display name, account identifier, video identifier, publish time and cumulative view count. Requested scopes are user.info.basic and video.list.

3. 使用目的

  • 筛选符合条件的直播订单并匹配到主播时段；
  • 按主播和直播账号统计GMV及佣金；
  • 核验登记视频是否属于已授权TikTok账号；
  • 核验发布时间、累计播放量及奖励达标情况；
  • 生成可供运营和财务复核的中间证据与结果文件；
  • 排查错误并保障工具安全运行。

4. 存储与传输

Excel原始文件、处理中间表和佣金结果默认在用户选择或工具创建的本地文件夹中处理和保存，不会上传到小斧科技团队运营的服务器。TikTok Client Secret、访问令牌和刷新令牌保存在当前Windows用户的本地加密存储中。

只有在使用TikTok授权或视频核验功能时，桌面应用会与TikTok官方授权页面及API服务器通信。TikTok对其收到的数据依照其自身隐私政策进行处理。

Source workbooks, evidence files and commission outputs are processed and stored locally and are not uploaded to servers operated by the Xiaofu Technology Team. TikTok credentials and tokens are kept in encrypted local storage for the current Windows user. Network transmission occurs only when communicating with official TikTok authorization and API services.

5. 共享、出售与保留

我们不出售用户数据，也不将本地业务文件用于广告。运营方不会主动接收这些本地文件。数据保留期限由用户控制：用户可以删除本地原始文件、结果目录和本地加密授权存储。TikTok接口可能按照TikTok自身规则保存必要的授权或访问记录。

6. 用户选择与权利

  • 用户可以选择不连接TikTok账号；直播佣金的本地表格流程仍可独立使用。
  • 用户可以在TikTok账号设置中撤销对本工具的授权。
  • 用户可以删除本地配置、授权存储和计算结果。
  • 如需了解、纠正或删除运营方实际持有的相关信息，可通过下方联系方式提出请求。

7. 数据安全

本工具采用Windows当前用户范围的本地加密机制保护Client Secret和TikTok令牌。用户仍应保护Windows账号、电脑和输出文件夹，并避免向他人公开Client Secret、令牌或包含业务数据的工作簿。

8. 儿童隐私

本工具面向电商运营和财务工作人员，不面向儿童，也不会有意收集儿童个人信息。

9. 政策更新

当功能、数据处理方式或法律要求发生变化时，我们可能更新本政策，并在页面顶部更新生效日期。

10. 联系方式

如有隐私问题或数据请求，请通过公开GitHub主页联系小斧科技团队：github.com/Gslullaby。

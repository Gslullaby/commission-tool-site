Windows desktop application

Salary Tools

Salary Tools is a Windows desktop application for livestream host commissions and video editor rewards. It helps operations and finance teams organize orders, match sales to host schedules, calculate GMV and tiered commissions, and check editor reward data through authorized TikTok APIs.

Core workflow

From source workbooks to reviewable results

Each stage produces a clear intermediate record so operations and finance teams can review how every result was calculated before payment.

01

Prepare livestream data

Combine order sheets, retain eligible completed LIVE orders, and standardize schedule and order timestamps.

02

Match and calculate

Match orders to the correct host and livestream account, summarize GMV, and apply configurable commission thresholds and rates.

03

Review evidence

Export filtered orders, match results, account-level GMV, exceptions, and final commission summaries for verification.

TikTok integration

Authorized verification for editor rewards

When an account holder chooses to connect a TikTok account, the application uses TikTok Login Kit and Display API to confirm account and video information used in the reward workflow.

  • Authorization takes place through TikTok's official sign-in flow.
  • The requested scopes are user.info.basic and video.list.
  • The application reads basic account details, video identifiers, publication times, and cumulative view counts.
  • Users can decline or revoke authorization at any time.
1
Account holder authorizes access

TikTok displays the requested permissions before consent.

2
The application retrieves permitted data

Only the account and video fields needed for verification are requested.

3
The user reviews the evidence

Verified view counts and exceptions are exported for commission review.

Data and security

Business files stay on the user's computer

Excel source files, intermediate evidence, configuration outputs, and commission results are processed and stored locally. They are not uploaded to servers operated by the Xiaofu Technology Team.

Local processing

Users choose the input files and output folder. Generated workbooks remain under the user's control.

Protected credentials

TikTok Client Secrets and authorization tokens are stored using encryption scoped to the current Windows user.

Limited network use

Network communication occurs only when using TikTok authorization or requesting permitted account and video data from official TikTok services.

No sale or advertising use

We do not sell personal data or use local business files for advertising.

Service region

Operated from Indonesia for TikTok-supported markets

The application is operated from Indonesia and is intended for e-commerce operations teams working in regions where TikTok and the relevant developer services are available.

It is not offered to users in mainland China and is not intended to access TikTok from mainland China-based IP addresses.
